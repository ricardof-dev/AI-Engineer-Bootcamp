# AI Engineer Bootcamp

Bootcamp personal de formación progresiva en **Python, Data Engineering, Cloud y AI Engineering**, con enfoque práctico y construcción incremental de proyectos para portafolio profesional.

## 🎯 Objetivo

Desarrollar las habilidades necesarias para evolucionar desde fundamentos de programación en Python hacia un perfil profesional orientado a:

- Data Engineering
- Cloud Data Engineering
- AI Engineering
- Data + AI

El aprendizaje se basa en práctica constante, resolución de problemas, proyectos, control de versiones y documentación técnica.
